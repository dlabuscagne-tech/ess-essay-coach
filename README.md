# ESS Essay Coach

A step-by-step practice tool for IB DP Environmental Systems and Societies (ESS) Paper 2, Section B structured essays (new guide, first assessment 2026), for SL and HL students.

Students:

1. **Decode** the question. Every command term can be clicked to see what it requires.
2. **Plan** in five minutes: conclusion first, named examples, arguments and counter-arguments, plus an HL lens.
3. **Write** parts a [4], b [7] and c [9] with timers and sentence starters.
4. **Self-assess** part c against the markbands and tick the marking points for parts a and b.
5. **Compare** with model answers at different markbands, then print, download or copy their work.

Drafts are saved only in the student's own browser.

## Files

- `index.html`: the page
- `data.js`: markbands, command terms, questions, marking points and model answers (edit this file to add or change questions)
